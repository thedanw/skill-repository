# Central Guidelines for Sermon Planning
Use these guidelines in prompts and responses for sermon planning.

## Citation Rules
1. **Succinct Credits [CITE]**: Use bracketed abbreviations immediately following any claim or insight (e.g., "The Hinge point is 8:29 [TGC]").
2. **Sources Cited**: Every output file **must** conclude with a `# Sources Cited` section for the sources used in that file. (e.g. - "[TGC]: The Gospel Coalition")
