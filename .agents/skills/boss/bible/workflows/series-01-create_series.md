# Series Setup (Step 1)

1. **Input**: Ask the user for the `Year` (e.g., 2026) and `Series Name` (e.g., Esther).
2. **Directory Creation**:
   - Create: `Sermons_n_Series/[Year]/[SeriesName]/00_Research/`
   - Create: `Sermons_n_Series/[Year]/[SeriesName]/00_Research/Sources/` (Optional: for raw PDFs)
3. **Template Discovery**: Search `01_Templates` for any series-level documentation.
4. **Handoff**: Once the structure is ready, inform the user they can now proceed to **Step 2: Research Pass**.
